# RK PayFlow Platform

A production-inspired payment platform built with Java 21, Spring Boot microservices, Apache Kafka, PostgreSQL and Docker.

## Project Goal

Build a production-style event-driven payment platform that demonstrates modern enterprise software engineering practices.

## Planned Microservices

- Account Service
- Transfer Service
- Notification Service

## Technology Stack

- Java 21
- Spring Boot 3
- PostgreSQL
- Apache Kafka
- Docker & Docker Compose
- Flyway
- Spring Data JPA
- JUnit 5
- Testcontainers

## Architecture

- Microservices
- Clean Architecture
- Domain-Driven Design (DDD)
- CQRS
- Event-Driven Architecture
- Transactional Outbox Pattern
- Idempotency
- Retry & Dead Letter Queue
